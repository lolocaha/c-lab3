# Задание 1

## Задача 2 (Заполнение двумерных массивов)

### Текст задачи

Первый массив, размерностью n x m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по столбцам от последних элементов столбца к первым.

Второй массив, размерностью n x n, заполняется так: элементы, лежащие выше главной диагонали, являются случайными числами из интервала [-4.5; 45.675], а лежащие на главной диагонали и ниже, являются случайными числами из интервала [-100; 100].

Третий массив, размерностью n x n, заполняется для произвольного n так же, как для n=5:

```
 1   2   6   7  15
 3   5   8  14   0
 4   9  13   0   0
10  12   0   0   0
11   0   0   0   0
```

### Алгоритм решения

1. Создаётся класс `OneTwoThree` с единственным приватным полем `double[,] array`. Тип `double` выбран потому, что в массивах встречаются и целые, и дробные числа.
2. **Первый массив.** Конструктор `OneTwoThree(int n, int m)` создаёт массив `n x m`. Внешний цикл идёт по столбцам `j` от `0` до `m-1`, внутренний по строкам `i` от `n-1` до `0` (от последнего элемента столбца к первому). Каждое значение запрашивается у пользователя и проверяется через `double.TryParse`: пока введено не число, запрос повторяется. Размеры `n` и `m` должны быть больше 0.
3. **Второй массив.** Конструктор с одним параметром `n` создаёт массив `n x n` и использует один объект `Random`. Элементы с `j > i` (выше главной диагонали) получают значение `rnd.Next(-4500, 45676) / 1000.0`, то есть число из `[-4.5; 45.675]`. Элементы с `j <= i` (на диагонали и ниже) получают значение из `[-100; 100]`.
4. **Третий массив.** Заполнение идёт по побочным диагоналям `i + j = d`, где `d` от `0` до `n-1`. Счётчик начинается с 1 и растёт на 1 с каждым записанным элементом. На диагоналях с чётным `d` строка `i` идёт от `d` до `0` (снизу вверх), с нечётным `d` от `0` до `d` (сверху вниз). Всё, что лежит ниже побочной диагонали, остаётся нулями.
5. Метод `ToString()` формирует строку-таблицу: каждое число занимает поле шириной 10 символов (формат `{0,10:0.###}`), после каждой строки массива добавляется перенос.
6. В `Main` показана работа всех трёх способов создания объекта.

# Задание 2

## Задача 2 (Минимальный из повторяющихся элементов)

### Текст задачи

Найдите минимальный из повторяющихся элементов двумерного массива.

### Алгоритм решения

1. Метод `MinDouble()` класса `OneTwoThree` возвращает `double?`: `null`, если повторяющихся элементов нет или массив пуст.
2. Для каждого элемента `array[i, j]` вторым проходом по всему массиву (индексы `k`, `l`, позиция самого элемента пропускается) ищется такой же элемент.
3. Если совпадение найдено, элемент считается повторяющимся и сравнивается с текущим минимумом. Если минимум ещё не задан или элемент меньше минимума, он становится новым минимумом.
4. После обхода всех элементов возвращается найденный минимум.
5. Метод проверен на готовом массиве, на массиве без повторов и на массиве, где повторяется только большее число.

# Задание 3

## Задача 2 (Матричное выражение)

### Текст задачи

Перегрузить необходимые операторы и посчитать значение матричного выражения (решение без перегрузки не принимается). Перегрузить метод ToString() для отображения массива в виде таблицы. Приложить в отчет скриншот проверки на онлайн-калькуляторе.

Выражение: **A + 2·B − 3·Cᵀ**

### Алгоритм решения

1. Для выражения нужны операции сложения матриц, вычитания матриц, умножения матрицы на число и транспонирования.
2. В классе `OneTwoThree` перегружены операторы `+`, `-` (поэлементно, с проверкой совпадения размеров) и `*` для матрицы на число. Для записи `2 * B` добавлена перегрузка `число * матрица`. Каждый оператор создаёт новый массив и возвращает новый объект, исходные матрицы не меняются.
3. Транспонирование реализовано методом `Transpose()`: создаётся массив размера `m x n`, и `result[j, i] = array[i, j]`.
4. В `Main` создаются три матрицы одинакового размера (для проверки взят небольшой размер, например 3x3), и выражение записывается в том же виде, что и в условии: `A + 2 * B - 3 * C.Transpose()`.
5. Матрицы A, B, C и результат выводятся через перегруженный `ToString()` в виде таблицы.
6. Те же матрицы вводятся в онлайн-калькулятор матриц, результаты сравниваются.

### Текст задачи

Вычислить произведение нечетных отрицательных компонент файла.

В задании 4 бинарные файлы содержат числовые данные, исходный файл необходимо заполнить случайными данными, заполнение организовать отдельным методом.

### Алгоритм решения

1. Метод заполнения `binFile4(string path)` создаёт бинарный файл через `BinaryWriter` и записывает 10 случайных целых чисел из интервала `[-10; 10)`.

5. Если подходящих чисел не нашлось, выводится соответствующее сообщение.

# Задание 5

## Задача 2 (Бинарные файлы и структуры)

### Текст задачи

Информация о багаже пассажира описывается массивом, где каждый элемент содержит название единицы багажа (чемодан, сумка, коробка и т.д.) и ее массу. Дан файл, содержащий сведения о багаже нескольких пассажиров. Найти число пассажиров, имеющих более двух единиц багажа и число пассажиров, количество единиц багажа которых превосходит среднее число единиц багажа.

Заполнение исходного файла организовать отдельным методом, обязательно использовать xml сериализацию.

### Алгоритм решения

1. Описываются две структуры с публичными полями (это требование `XmlSerializer`): `Baggage` (название `Name` и масса `Weight`) и `Passenger` (массив `Baggage[] Items`).
2. Метод заполнения создаёт массив пассажиров со случайным числом единиц багажа (от 1 до 5) и случайными массами. Массив сохраняется в файл через `XmlSerializer` и `FileStream`.
3. Метод решения читает файл через `XmlSerializer.Deserialize` и получает массив пассажиров.
4. Подсчитывается число пассажиров, у которых `Items.Length > 2`.
5. Вычисляется среднее число единиц багажа на пассажира (сумма `Items.Length` делится на число пассажиров). Подсчитывается число пассажиров, у которых `Items.Length` больше среднего.
6. Оба числа выводятся на экран. Работа с файлом обёрнута в `try/catch`.
